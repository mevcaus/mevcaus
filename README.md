## What I'm working on

- **shop-watch** (private, it's paid work): a Go service on an Ubuntu server that watches Shopify stores and sends restock alerts to 10 paying subscribers through Discord.
- **[GoProxy](https://github.com/mevcaus/goproxy)**: a Layer 7 HTTP load balancer in Go using only the standard library. Round-robin and least-connections routing with health checks.
- **IPDES UAT Framework** (senior design): acting lead on a four-person team building a test-tracking tool for the Idaho Department of Environmental Quality.
